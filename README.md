# Hrutin Nammi Portfolio

Personal portfolio website for Hrutin Nammi, focused on AI engineering, full-stack product work, startup projects, and automation systems.

Live site:

```text
https://hrutinnammi.in
```

## What It Shows

- AI/ML engineering profile
- Featured projects and startup work
- Skills across AI, backend, frontend, automation, and deployment
- Resume and contact links
- Responsive portfolio UI built for recruiter review

## Tech Stack

| Layer | Stack |
| --- | --- |
| Framework | Next.js |
| Language | TypeScript |
| Styling | Tailwind CSS |
| UI | React components, custom sections |
| Deployment | Static export / GitHub Pages-ready output |

## Project Structure

```text
app/             Next.js app routes and metadata
components/      shared UI components
sections/        portfolio page sections
lib/             portfolio data and icon mapping
public/          resume, profile photo, and public assets
```

## Getting Started

```bash
git clone https://github.com/HRUTIN/portfolio.git
cd portfolio
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Build

```bash
npm run build
```
